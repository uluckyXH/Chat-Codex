Chat-Codex v0.1.7 修复自动审批成功提示频繁推送到微信／飞书、挤占正常回复发送机会的问题，对应 [Issue #7](https://github.com/uluckyXH/Chat-Codex/issues/7)。

## 安装 / 升级

npm `0.1.7` 由维护者单独发布；请在 npm 版本发布后执行：

```bash
npm install -g chat-codex@0.1.7
chat-codex --version
chat-codex
```

升级前停止旧进程，升级后重新启动。运行需要 Node.js 22+；本次修复默认生效，无需新增配置。

## 优化项

- 【优化】明确的“自动审批已通过”通知仅记录到本机 INFO 日志，保留会话、通知来源和完整说明，不再逐条推送聊天渠道。
- 【优化】微信私聊、飞书私聊／群聊，前台任务与后台续跑使用同一通知分流规则；成功提示不再占用 `/status` 的最近重要通知位置。
- 【优化】安装包验证增加通知行为检查，在隔离安装后的真实 npm 包中确认成功提示仅本地记录，拒绝提示与最终正文继续发送。

## 修复项

- 【修复】修复自动审批成功提示绕过静默进度设置，以及审批理由变化后无法被相同正文去重抑制的问题。成功提示在进入渠道发送队列前分流，减少对正常回复发送机会的占用。
- 【修复】补齐成功通知的独立本地日志，避免停止渠道投递后无法排查，同时避免产生虚假的“已发送”日志。

自动审查拒绝、失败、超时和未知安全提示继续保留；人工审批、用户问题、工作进展旁白和推理摘要按原有流程处理。此修复减少无用发送，不能消除微信平台本身的限流，也不包含通用长文本分段或发送失败补发功能。

本版通过 95 项定向测试、742 项全量自动化测试、9 组独立安装包检查及 npm 发布演练；生产依赖已知漏洞审计为 0 项。真实微信／飞书送达仍需现场验收，详见[修复测试报告](https://github.com/uluckyXH/Chat-Codex/blob/main/reports/tests/2026-10-16-issue-7-auto-review-notifications.md)与[发布验证报告](https://github.com/uluckyXH/Chat-Codex/blob/main/reports/tests/2026-10-16-release-0.1.7.md)。
